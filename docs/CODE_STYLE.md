# Правила кода

## Язык и движок
- Godot 4.7, только **GDScript** со статическими типами (`var x: int`, `-> void`).
- Отступы — табы (по умолчанию в Godot), кодировка UTF-8 (`.editorconfig`).

## Имена
| Что | Как | Пример |
|---|---|---|
| Файлы и папки | `snake_case` | `main_menu.gd`, `scenes/ui/` |
| Классы (`class_name`) | `PascalCase` | `ItemDef` |
| Узлы в сценах | `PascalCase` | `NewGameButton` |
| Функции и переменные | `snake_case` | `load_language()` |
| Приватные поля/функции | с `_` в начале | `_hint_label` |
| Константы | `UPPER_SNAKE_CASE` | `SETTINGS_PATH` |
| Сигналы | глагол в прошедшем времени | `day_ended`, `money_changed` |

## Устройство
- **Логика отдельно от картинки.** Экономика, люди, полиция — в `scripts/sim/`, без обращения к узлам сцены. Графика (`scripts/ui/`, сцены) только показывает данные и отправляет команды.
- Числа баланса — в `data/`, не в коде. Описание чисел — в `docs/BALANCE.md`.
- Тексты для игрока — только ключи перевода (`MENU_NEW_GAME`) в `data/i18n/strings.csv`, сразу на `en` и `ru`.
- Узлы, которые нужны скрипту, помечаем «уникальным именем» и берём через `%Имя`.
- Комментарии — коротко и по-русски, в начале файла `##` — что это за файл.

## Папки
```
assets/   модели, текстуры, звук, шрифты (каждый — в docs/ASSETS.md)
data/     описания товаров, городов, рецептов; i18n/ — переводы
scenes/   world/, city/, ui/, actors/
scripts/  core/, sim/, ai/, ui/
autoload/ глобальные системы (появятся на этапе 1)
tests/    автотесты логики
docs/     план, баланс, ассеты, эти правила
```

## Проверка перед «готово»
1. Игра запускается без ошибок в выводе.
2. Изменение видно/работает (скриншот или проверочный скрипт).
3. Для логики — автотест в `tests/` (с этапа 1).
